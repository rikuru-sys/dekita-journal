# できたこと記録

毎晩、その日にできたこと、気分、体調を振り返るための個人用アプリです。

## 試し方

1. 「振り返り」で当てはまる項目にチェックします。天気、気分、体調、メモは任意です。天気は「晴れ」「曇り」「雨」から選びます。
2. 「振り返りを保存」を押します。チェックが0件の日も保存できます。
3. 「カレンダー」で日付を選ぶと、天気などの記録を確認できます。「この日の記録を編集」から保存内容を変更できます。「見本を表示」で色分けと集計を試せます。見本データは保存されません。
4. 「項目管理」で項目を追加・編集できます。「並び替え」で同じカテゴリ内の順番を上下の矢印で変更します。変更はすぐに保存され、振り返りにも反映されます。
5. 項目の編集画面から削除できます。アーカイブ済みの項目も、一覧から削除または復元できます。削除した項目の保存済み記録はカレンダーで確認できます。

カレンダーは月間・年間と「できたこと」「気分」「体調」を切り替えられます。「できたこと」はカテゴリ・項目で絞り込めます。月間集計には実施日数と気分・体調の分布を表示し、その月に保存した0件の日も記録日数に含めます。

### 体調の参考評価

疲労感、眠気、身体的不調、活動への支障を一日全体で振り返ります。4項目すべてを選んだとき、「なし」0点、「少し」1点、「強い」2点の合計で評価します。

| 症状の合計点 | 参考評価 |
| --- | --- |
| 0 | 5 良好 |
| 1〜2 | 4 おおむね良好 |
| 3〜4 | 3 やや不調 |
| 5〜6 | 2 つらい |
| 7〜8 | 1 かなりつらい |

「記録する評価」で選び直した値は、カレンダーと月間集計にも反映されます。未入力の症状がある日は手動で評価を選べます。

### リマインダーとバックアップ

- 「設定」でリマインダーの時刻と有効・無効を保存します。初期時刻は20:30です。毎晩のアラームはAndroidの時計アプリで同じ時刻を選び、繰り返しの曜日をすべて指定します。時刻の変更や停止は時計アプリ側でも行います。[Androidの時計アプリの設定手順](https://support.google.com/android/answer/2840926?hl=ja)
- 「設定」→「バックアップ」で、記録・チェック項目・リマインダー設定をJSONに書き出せます。「ファイルから復元」でファイルを選び、確認画面で端末のデータをその内容に置き換えます。

## ローカルで起動

Node.js 24を使用します。

```sh
npm ci
npm run dev
```

`npm test` でテスト、`npm run build` で型検査と本番用ビルドを実行します。Service Workerを含むビルドを試すには、ビルド後に `npm run preview` を実行します。

## GitHub Pages

GitHubリポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定します。同梱の `.github/workflows/pages.yml` が `main` へのプッシュ時と手動実行時にテスト、ビルド、公開を行います。Viteの相対ベースパスとハッシュ形式の画面URLにより、リポジトリ名を含むURLにも配置できます。

AndroidではHTTPSで開いたページから、ブラウザーのメニューでホーム画面に追加できます。初回の読み込み後、Service Workerがアプリのファイルをキャッシュします。記録はブラウザーとサイトURLごとのIndexedDBに保存されます。

[GitHub Pagesのカスタムワークフロー](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages) · [Viteの静的サイト配信ガイド](https://vite.dev/guide/static-deploy)

## 画面遷移

| 画面 | URL | 次の操作 |
| --- | --- | --- |
| 今日の振り返り | `#/today` | 日付を選ぶ、項目管理を開く |
| カレンダー | `#/calendar/YYYY-MM-DD` | 日付を選択して記録を開く |
| 日付を指定した振り返り | `#/today/YYYY-MM-DD` | 編集して保存、カレンダーに戻る |
| 設定 | `#/settings` | 項目管理、リマインダー設定、JSONバックアップと復元 |

## データ型

`src/model.ts` に画面と集計で共通の型を定義し、`src/db.ts` でDexieを通して保存します。

| IndexedDBのテーブル | 主キー | 内容 |
| --- | --- | --- |
| `items` | `id` | 項目名、カテゴリ、予定（毎日・指定曜日・予定なし）、メモ欄、表示順、アーカイブ状態 |
| `days` | `date`（端末の日付） | チェック状態、項目の保存時の情報、項目メモ、セルフケア効果、天気、気分、症状、体調の手動評価、日全体のメモ、保存日時、更新番号 |
| `settings` | `id` | リマインダー時刻、有効・無効、復元を識別する更新値 |

`days` に行がある日を記録済みと判定します。過去の実施記録は保存時点の項目名とカテゴリを参照します。天気・気分・体調の欄は任意で、以前のバージョンで該当する欄がない記録は未入力として扱います。保存時に更新番号と復元後の状態を確認し、別のタブからの古い入力での上書きを防ぎます。
